# Security Policy

This repository holds documentation only: an index of the Aspose Cloud MCP servers. It contains no server code, no
credentials and no build artifacts.

## Reporting a vulnerability

Please report a suspected vulnerability privately. Do not open a public issue for it.

- A vulnerability **in one of the servers** belongs in that server's repository, which has its own policy. The servers
  are listed in [`README.md`](README.md).
- A problem with **this repository** (for example, a link in the README that points to the wrong place):
  1. Use GitHub's private vulnerability reporting:
     <https://github.com/aspose-cloud/aspose-total-cloud-python-mcp/security/advisories/new>
  2. Or email shahzad.latif@aspose.com.

Every report is read and the reporter gets a reply. There is no guaranteed response time.

## Secrets in this repository

Secrets are never committed. If you find one, report it as above.
