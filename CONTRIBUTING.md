# Contributing

This repository is an index of the Aspose Cloud MCP servers. It has no code of its own; the README is maintained by
the servers' build system and is regenerated, so a pull request cannot be merged here.

To suggest a correction, open an issue that names the line in the README and what it should say.

For a bug or a missing tool in one of the servers, open the issue in that server's repository (linked from the README).
For a security problem, follow [`SECURITY.md`](SECURITY.md) and do not open an issue.
